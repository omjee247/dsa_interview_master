"If the Interviewer Twists the Question..." — 16-Category Instant Algorithm Selector

Filter or scan the 16 twist families below. Whenever an interviewer changes a constraint mid-interview, match the twist on the left to the exact algorithm on the right:

1. Subarray Sum & Window Twists
• All positive numbers, shortest subarray ≥ K → Shrinkable Sliding Window O(n) (LC 209)
• Contains NEGATIVE numbers, count/longest sum == K → Prefix Sum + Hash Map O(n) (LC 560)
• Contains NEGATIVE numbers, shortest subarray ≥ K → Prefix Sum + Monotonic Increasing Deque O(n) (LC 862)
• Subarray sum divisible by K → Prefix Sum mod K in Hash Map ((sum % k) + k) % k (LC 974)
• Circular array maximum subarray sum → max(MaxKadane, TotalSum - MinKadane) O(n) (LC 918)
2. Pair, Tuple & k-Sum Twists
• Unsorted array, find 2 numbers summing to T → One-Pass Complement Hash Map O(n) (LC 1)
• Sorted array, O(1) extra space required → Converging Two Pointers l=0, r=n-1 O(n) (LC 167)
• 3Sum / 4Sum with duplicate elements → Sort + Fix outer loops + Two Pointers + skip equal (LC 15)
• Count pairs with sum < T or triangle sides → Sort + Two Pointers adding (r - l) at once
• Four independent arrays (4Sum II) → Hash Map of A[i]+B[j] + lookup -(C[k]+D[l]) O(n²)
3. In-Place Array Compaction & Merging Twists
• Order of kept elements MUST be preserved → Slow/Fast Read-Write Pointers nums[k++] = x (LC 26, 27)
• Order does NOT matter & writes are costly → Opposite-Ends Swap nums[l] = nums[r--] (re-check l!) (LC 27)
• Keep at most m copies in sorted array → Compare against kept prefix nums[i] != nums[k - m] (LC 80)
• Buffer space is at the END of array 1 → 3 Pointers filling backwards from m + n - 1 (LC 88)
• 3-way partition (0s, 1s, 2s / Dutch Flag) → 3 pointers low, mid, high in one pass (LC 75)
4. Binary Search Variations & Rotated Twists
• Rotated sorted array (distinct values) → Check which half is sorted via a[l] <= a[m] (LC 33)
• Rotated sorted array WITH DUPLICATES → When a[l] == a[m] == a[r], shrink l++, r-- (LC 81)
• Find minimum in rotated sorted array → Compare a[m] with a[r] (never a[l]!) (LC 153)
• "Minimize the maximum" or "minimum speed/capacity" → Binary Search on Answer Space [lo, hi] + greedy check (LC 875)
• Unsorted array, find any local peak → Binary search slope: compare a[m] vs a[m+1] (LC 162)
5. Stack, Queue & Monotonic Twists
• Next Greater / Smaller Element to the right/left → Monotonic Decreasing/Increasing Stack of indices (LC 739)
• Circular array Next Greater Element → Loop i from 0 to 2n - 1 indexing a[i % n] (LC 503)
• Largest rectangle in histogram / binary matrix → Monotonic Increasing Stack with trailing 0 sentinel (LC 84)
• Maximum / Minimum in every sliding window of size K → Monotonic Deque of indices (evict front when <= i - k) (LC 239)
• Calculator with + - ( ) vs + - * / → Sign stack on '(' (LC 224) vs folding * / into st.top() (LC 227)
6. Linked List Pointer Twists
• Head node might be deleted or moved → Stack-allocated ListNode dummy(0, head) (LC 19, 82, 92)
• Detect cycle AND find cycle entry node → Floyd's slow/fast meet, then reset one pointer to head at 1x speed (LC 142)
• Clone list with random pointers in O(1) space → Interleave A -> A' -> B -> B', wire random, unweave (LC 138)
• Sort linked list in O(n log n) & O(1) space → Bottom-up Merge Sort (splitting by size 1, 2, 4, 8...) (LC 148)
• Reverse in k-groups (leave remainder untouched) → Lookahead k nodes first; only reverse if k exist (LC 25)
7. Binary Tree & BST Twists
• Max path sum (can arch through root) → Update global with val + L + R, return val + max(L, R) to parent (LC 124)
• LCA in Binary Tree vs LCA in BST → Postorder propagation O(n) (LC 236) vs value split walk O(h) (LC 235)
• Validate BST with INT_MIN / INT_MAX values → Pass 64-bit (long lo, long hi) strict bounds (LC 98)
• Count nodes in Complete Binary Tree < O(n) → Compare left-spine height of left & right children O(log² n) (LC 222)
• O(1) space traversal (no recursion stack allowed) → Morris Traversal (thread rightmost predecessor to current) (LC 114)
8. Graph Shortest Path & Connectivity Twists
• Unweighted shortest path → Standard Queue BFS O(V + E) (LC 909, 433)
• Known start AND target with huge branching (Word Ladder) → Bidirectional BFS expanding smaller frontier (LC 127)
• Multiple starting sources (rotting oranges / fire spread) → Multi-Source BFS (push all sources at t = 0) (LC 994)
• Edge weights are 0 or 1 only → 0-1 BFS using Deque (push_front for 0, push_back for 1)
• Non-negative weighted shortest path → Dijkstra with Min-Heap O((V + E) log V) (LC 743)
• Prerequisite ordering / directed cycle detection → Kahn's Indegree BFS (cycle iff done < n) (LC 207, 210)
• Dynamic undirected connectivity / redundant edge → Union-Find (Disjoint Set) with path compression (LC 684)
9. Dynamic Programming: Knapsack & Sequence Twists
• 0/1 Knapsack (each item used at most once) → Iterate capacity w BACKWARDS from W down to item (LC 416)
• Unbounded Knapsack (unlimited coin reuse, min coins) → Iterate amount FORWARDS from coin up to amount (LC 322)
• Coin Change COMBINATIONS vs PERMUTATIONS → Outer loop coins = combinations (LC 518); Outer loop amount = permutations (LC 377)
• House Robber on a Circle (first & last adjacent) → max(rob(0..n-2), rob(1..n-1)) (LC 213)
• Longest Increasing Subsequence for n = 10⁵ → Patience Sorting with lower_bound on tails O(n log n) (LC 300)
10. Stock Trading DP Twists (All 6 Variants)
• At most 1 transaction → Track minPrice & max(profit, p - minPrice) O(n) (LC 121)
• Unlimited transactions (no fee) → Greedy sum of all positive p[i] - p[i-1] O(n) (LC 122)
• At most 2 transactions → 4 variables: buy1, sell1, buy2, sell2 O(n) (LC 123)
• At most K transactions → Arrays buy[1..k], sell[1..k] O(n·k) (LC 188)
• With 1-day Cooldown after selling → 3 states: hold, sold, rest (buy transitions from rest) (LC 309)
• With transaction fee → Subtract fee when transitioning into sell (LC 714)
11. Backtracking & Combinatorial Twists
• Subsets / Combinations (no duplicates in input) → Recurse with i + 1 (LC 77, 78)
• Input HAS DUPLICATES, output must have unique subsets → Sort first + skip if (i > start && a[i] == a[i-1]) continue; (LC 90, 40)
• Elements can be reused unlimited times → Recurse with same index i (not i + 1) (LC 39)
• Permutations of array WITH duplicates → Sort + skip if (i > 0 && a[i] == a[i-1] && !used[i-1]) (LC 47)
• Board search for 1 word vs 10,000 words → Single DFS (LC 79) vs Trie-guided DFS pruning dead prefixes (LC 212)
12. Intervals & Sweep-Line Twists
• Merge overlapping intervals → Sort by START ascending; merge if cur.start <= prev.end (LC 56)
• Minimum arrows / non-overlapping intervals to keep → Sort by END ascending; greedily pick earliest ending (LC 452, 435)
• Minimum meeting rooms / peak concurrent load → Sort starts & ends (Sweep-Line) OR Min-Heap of end times (LC 253)
• Insert into already-sorted disjoint intervals → 3-phase linear scan in O(n) without sorting (LC 57)
13. Heaps, Top-K & Streaming Twists
• Kth largest in static array (O(1) space) → Quickselect 3-Way Partition O(n) average (LC 215)
• Kth largest in an unbounded stream → Min-Heap of size K O(log k) per element (LC 703)
• Top-K frequent elements (frequencies ≤ n) → Bucket Sort buckets[freq] in strict O(n) (LC 347)
• Live median of data stream → Max-Heap (left half) + Min-Heap (right half) O(log n) (LC 295)
• Smallest sum pairs across 2 sorted arrays → Min-Heap seeded with (i, 0) advancing j -> j+1 (LC 373)
14. Trie & String Matching Twists
• Exact substring match in worst-case O(n + m) → KMP Algorithm (Longest Prefix-Suffix table) (LC 28)
• Fast prefix search / autocomplete → 26-way Trie caching top-K hot strings at every node (LC 208, 642)
• Regex wildcard . in dictionary lookup → Trie + DFS branching across all 26 children on '.' (LC 211)
• Longest Palindromic Substring in O(1) space → Expand Around 2n - 1 Centers (odd & even) (LC 5)
15. Bit Manipulation & Math Twists
• Every element appears TWICE except one → XOR all numbers ans ^= x O(n) time, O(1) space (LC 136)
• Every element appears THREE times except one → Modulo-3 bit state machine ones, twos (or sum 32 bits % 3) (LC 137)
• TWO elements appear once, all others twice → XOR all = a^b; split array by lowest set bit diff & -diff (LC 260)
• Count set bits / power of two check → Brian Kernighan n &= n - 1; power of 2 iff n > 0 && !(n & (n-1)) (LC 191)
16. Cache, Rate-Limiting & System Design Twists
• O(1) LRU Cache vs O(1) LFU Cache → Map + 1 DLL (LC 146) vs KeyMap + FreqMap of DLLs + minFreq (LC 460)
• O(1) Insert, Delete, AND GetRandom (unique vs duplicates) → Vector + Map swap-with-back (LC 380; use unordered_set of indices for duplicates LC 381)
• Add/remove cache servers without remapping all keys → Consistent Hashing Ring with virtual nodes + upper_bound (#166)
• Allow bursts up to B but cap average rate R → Token Bucket with lazy timestamp refill math (#167)
• Check if key definitely does NOT exist in 1B keys using 1MB RAM → Bloom Filter (k hash functions over m-bit array) (#169)
